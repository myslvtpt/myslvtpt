# SLV Tours & Travels — MICE Website

A responsive, single-page website introducing SLV Tours & Travels' Meetings, Incentives, Conferences and Exhibitions (MICE) services.

## Features
- Responsive landing page with service overview
- MICE event planning process and destination showcase
- Interactive enquiry form with client-side validation
- Contact call-to-action links
- No build tools or dependencies required

## Run locally
Open `index.html` in any modern browser.

## Before publishing
- Replace the placeholder phone number and email address in `index.html` with verified business contact details.
- Connect the enquiry form to an email, CRM, or server endpoint. The current version validates inputs in the browser and opens a pre-filled email draft.
- Add your official logo and real event photographs if available.

## Deploy
GitHub Pages can host this static site. In the repository settings, enable Pages for the `main` branch and root directory.
